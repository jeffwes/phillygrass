# Phillygrass website

A plain HTML/CSS/JS site for the band Phillygrass. You don't need to build anything.

## Preview locally

Open `index.html` in a browser, or run:

```
python3 -m http.server 8000
```

then visit http://localhost:8000.

## Common edits

- **Shows:** edit `shows.js`. Past dates are hidden automatically.
- **Bio and members:** edit the About section in `index.html`.
- **Photos:** put them in `images/`. For the hero, set the background in `styles.css` (look for `.hero`).
- **Music/video:** paste embed codes from YouTube, Spotify or Bandcamp into the Music section.
- **Colors and fonts:** the variables at the top of `styles.css`.

Places that still need real content are marked `TODO` in `index.html`.
